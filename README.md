## Sobre o repositório
Esse repositório contém os trabalhos desenvolvidos para a disciplina de Arquitetura de Computadores para o 3º semestre do curso de Ciência da Computação na Universidade Federal do Paraná. Foram desenvolvidos três processadores baseados nos conteúdos vistos em aula:
- Monociclo: Uma arquitetura em que toda instrução é executada por um único ciclo de clock. O processador desenvolvido é baseado na arquitetura 8 bits inspirada no RiscV, o ReduxV.
- VLIW: Cada instrução longa é um conjunto de várias outras instruções menores, essas são executadas simultaneamente. O processador desenvolvido é baseado na arquitetura Sagui, desenvolvida e destinada para a disciplina.
- Vetorial: Desenvolvido por @GiuTP, essa arquitetura é projetada para executar uma única instrução em várias unidades em paralelo. O processador desenvolvido é baseado na arquitetura Sagui, desenvolvida e destinada para a disciplina.


## Tecnologias e ferramentas utilizadas
 - Logisim Evolution v3.8.0
